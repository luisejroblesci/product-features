Smarter Testing · Local Installation

Local Onboarding Flow

Complete user journey from Org Home discovery through TIA activation. Branch points show the recommended option alongside alternatives.

Ideal path
Decision point
Alternate path
Success state
Iterate / loop
1
Discovery
Org Home — eligibility signal visible
User views the Org Home projects list. An amber ⚡ Optimize tests badge appears on eligible pipeline rows, surfacing Test Impact Analysis availability without requiring any navigation.
2
Entry point
Click "Set up Smarter Testing"
User clicks the CTA in the pipeline feature panel. The Smarter Testing onboarding wizard opens as a modal.
3
Wizard · Step 1 — Decision
VCS check
Wizard checks whether the CircleCI GitHub App is already installed for this org.
3a
No app installed
User clicks "Install CircleCI GitHub App ↗" — GitHub opens in a new tab. After installing, user returns and clicks Continue.
3b
App already installed
Step 1 is automatically skipped. Wizard advances directly to job selection.
Ideal
4
Wizard · Step 2 — Decision
Select test job
Wizard displays test jobs detected in .circleci/config.yml. A recommended job is pre-selected based on eligibility signals.
4a
Configure all eligible jobs
User skips job selection — all eligible jobs will be included in the setup prompt.
→ Skip to step 6
4b
Configure suggested job
User reviews the pre-selected job (e.g. run-tests), optionally searches for another, and clicks Continue.
Ideal
5
Wizard · Step 3
Select Local installation path
Wizard presents two options: Local (AI assistant + terminal) and CircleCI UI (auto-creates PR, no local setup). User selects Local.
Path 4a bypasses this step and jumps directly to step 6.
6
Wizard · Local path
Complete setup prompt displayed
Wizard renders the full setup prompt pre-filled with the selected job name and branch target (circleci/smarter-testing-setup). User clicks "Copy all instructions" — prompt is copied to clipboard.
7
Terminal
Open repository in terminal
User opens a terminal session at the root of the target repository. A persistent amber banner appears above the CircleCI app to track setup progress while the wizard is open or closed.
8
AI assistant
Paste prompt into AI assistant
User opens their AI coding assistant (Claude, Cursor, Copilot, or similar) and pastes the copied prompt. The AI reads the full instructions and begins setup.
9
AI assistant + user
Follow instructions · Run doctor
AI creates test-suites.yml and updates .circleci/config.yml with the Smarter Testing configuration. User runs the validation command when prompted by the AI.
10
Validation — Decision
Doctor results
The doctor command validates the Smarter Testing configuration and reports any issues with the generated files.
10a
All checks pass ✓
AI pushes the branch and opens a PR on circleci/smarter-testing-setup. Wizard shows a "PR detected" banner.
Ideal
10b
Errors found
Review AI output and error details. Correct the configuration, re-run doctor. Iterate until all checks pass.
↩ Back to 8
11
GitHub
Merge PR into main
User reviews and merges the circleci/smarter-testing-setup PR on GitHub. Wizard detects the merge event and advances to the final screen — or user confirms manually via "I've merged the PR."
12
Activation
TIA active — Test Insights populating
On the next pipeline run, CircleCI reads test-suites.yml and activates Test Impact Analysis for the selected job. Test Insights begins showing selected vs. total test counts and per-run savings data.
